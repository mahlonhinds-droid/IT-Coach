# Spreadsheet Workspace 2.0

Added prototype frameworks for:
- absolute-reference recognition
- cell/reference normalization
- search/find across cells
- multiple worksheet storage
- teacher-authored task validation

## Validation
Tasks can define expected cell outcomes. The validator compares the student's calculated cell value with the task criterion.

## Source alignment
These capabilities support Topic 5 areas including formulae/functions, absolute references, layout/data handling, and spreadsheet applications.

## Production requirements
The prototype does not yet implement full spreadsheet semantics. Teacher-authored validation criteria must be reviewed against final source materials. Multiple worksheets and absolute-reference calculation require full formula-engine integration before they should be presented as complete spreadsheet functionality.
