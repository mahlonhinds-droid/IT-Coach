# Database Workspace 2.0

Topic 6 now includes a second-stage database learning environment.

## Added capabilities
- Table relationships
- Parent/child join preview
- Multi-condition query builder functions
- AND/OR query logic
- Calculated-field definitions
- Form definitions
- Report definitions
- Browser-only persistence

## Educational purpose
The workspace gives students a place to practise the database concepts covered in Topic 6, including relationships, queries, forms and reports.

## Current prototype limitation
The UI is intentionally lightweight. It is not intended to emulate a commercial DBMS. Full referential-integrity enforcement, SQL execution, visual report layout, and a complete form designer remain future work.

## Source alignment
The Complete Draft identifies relationships, queries, calculated fields, forms/sub-forms, reports, sorting and grouping as Topic 6 skills. Formal SBA assessment should use teacher-approved criteria.
