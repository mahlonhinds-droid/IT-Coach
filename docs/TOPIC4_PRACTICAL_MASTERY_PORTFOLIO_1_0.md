# Topic 4 Practical Mastery Portfolio 1.0

Topic 4 practical attempts can now be recorded as mastery evidence.

## Recorded information
- lab/challenge
- practical score
- prototype mastery band
- unmet evidence criteria
- attempt date
- growth from the previous recorded attempt

The portfolio uses browser-only localStorage and can later feed teacher reports.

## Learning model
The portfolio complements quiz/assessment results rather than replacing them. Topic 4 mastery can therefore incorporate both knowledge evidence and practical application evidence.

## Status
Prototype. Teacher-approved rubrics and final source review remain required before formal assessment use.
