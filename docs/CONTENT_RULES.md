# IT Coach Content Rules

1. Student-facing content must be traceable to the supplied workbook or explicitly labelled as an added instructional feature.
2. Do not silently change terminology, lesson sequence, assessment structure or marking guidance from the source books.
3. Draft assessment weightings remain configurable until the final approved books are supplied.
4. Teacher-book material is teacher-facing unless the author explicitly approves student exposure.
5. Every assessment question should be tagged to course, topic, lesson and objective where the source supports those tags.
6. Any AI Coach response used in production should be grounded in approved course content.
7. New content should be reviewed before it is promoted to the production branch.
