# Topic 4 Teacher Intervention Planner 1.0

The teacher view now groups students whose latest practical score for a Topic 4 challenge is below the prototype mastery threshold.

## Priority
- High: 5 or more students
- Medium: 3–4 students
- Low: 1–2 students

Teachers can create a browser-local intervention group for a practical skill area.

## Intended classroom loop
Identify common gap → create intervention group → teach/review skill → students revise practical artifact → reassess → update mastery.

These priority rules are prototype rules and are configurable.
