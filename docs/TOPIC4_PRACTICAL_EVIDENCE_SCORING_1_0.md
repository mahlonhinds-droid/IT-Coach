# Topic 4 Practical Evidence Scoring 1.0

Topic 4 Skills Lab activities now have prototype evidence rubrics.

## Scoring
Each lab has teacher-reviewable criteria with configurable weights. The runtime awards the configured weight when the prototype detects supporting evidence.

Prototype bands:
- 80–100: mastered
- 70–79: developing
- below 70: needs revision

These thresholds are prototype learning rules, not official CXC grading rules.

## Evidence sources
Evidence may come from:
- workspace artifacts
- structured lab evidence
- saved browser state
- student descriptions of work

## Next integration
Connect the practical score to the existing mastery, remediation and reassessment engines, while keeping teacher approval as the final gate for formal practical assessment.
