# Topic 6 Visual Database Builders 1.0

The browser-only Database Workspace now includes prototype visual builders for:

- Queries: choose field, operator, value and optional second condition with AND/OR.
- Forms: select fields for a data-entry form and save the form definition.
- Reports: choose grouping and sorting fields and save the report definition.

## Learning purpose
These builders turn the Topic 6 concepts into visible student actions rather than only text explanations.

## Current limitations
This remains a learning prototype. It does not provide full SQL, referential-integrity enforcement, a commercial database engine, or a complete visual report designer.

## Source alignment
The Complete Draft identifies query criteria, AND/OR, calculated fields, forms, sub-forms, reports, sorting and grouping as Topic 6 skills. Formal assessment criteria should remain teacher-approved.
