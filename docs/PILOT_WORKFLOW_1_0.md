# IT Coach Pilot Workflow 1.0

## Student
1. Open dashboard.
2. View assigned topics.
3. Open assignment.
4. Complete lessons and activities.
5. Take topic assessment.
6. Receive score, skill breakdown and recommended action.
7. Complete remediation when required.
8. Reassess.
9. Return to dashboard and review progress.

## Teacher
1. Open teacher dashboard.
2. Create topic assignment.
3. Monitor assignment status.
4. Review topic assessment evidence.
5. Use intervention recommendation.
6. Reassign/reassess after remediation.

## Browser-only constraint
The current prototype stores assignment and assessment data locally in the browser. It is therefore suitable for controlled demonstrations and single-browser pilot testing, but it does not yet synchronize multiple student devices.

## Production transition
The same workflow can later be backed by authentication, classes, secure cloud persistence and role-based permissions without changing the conceptual learning cycle.
