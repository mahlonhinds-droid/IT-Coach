# Presentation Workspace 1.0

## Browser-only prototype
Students can:
- create slides
- edit slide titles and content
- add and delete slides
- reorder slides
- preview the presentation
- submit for teacher review
- retain work in browser storage

## Topic 4.3 alignment
The workspace provides an initial environment for presentation software practice.

## Prototype validation
Teacher-authored checks can validate minimum slide counts, titles and content.

## Production direction
Add images/media, themes/layouts, transitions, speaker notes, richer slide objects, artifact export and teacher-approved rubrics. These must be mapped to final approved source materials before formal assessment use.
