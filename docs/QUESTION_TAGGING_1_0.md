# IT Coach Question Tagging 1.0

Each assessment item can carry:
- course
- topic
- lesson
- skill/objective
- question type
- difficulty
- assessment paper/type

The prototype tagged bank contains demonstration MCQs across all eight topics.

## Skill scoring
For a completed tagged assessment, correct responses are grouped by skill and converted into a percentage.

## Production rule
The current questions are prototype items and must be reviewed against the final approved workbook and teacher materials before being treated as production assessment content.

## Adaptive use
Skill scores become evidence for:
1. identifying weak objectives;
2. selecting targeted lessons/practice;
3. assigning remediation;
4. triggering reassessment;
5. updating mastery.
