# Topic 6 Targeted Remediation and Reassessment 1.0

When a student's Topic 6 practical mastery record contains skills below 80%, the prototype identifies those skills and maps them to the relevant Topic 6 lessons.

Mappings:
- Database Design → 6.1–6.2
- Queries → 6.3
- Forms / Sub-form → 6.3
- Reports → 6.3

The intended loop is:

Assess → identify weak skill → targeted revision → practical activity → reassess → compare growth.

The 80% threshold is a configurable prototype rule and is not an official CXC grade boundary.
