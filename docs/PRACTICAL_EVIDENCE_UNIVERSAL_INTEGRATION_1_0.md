# Practical Evidence Universal Integration 1.0

The universal evidence layer now has a bridge for practical evidence from the Topics 1–3 mastery records and a reusable function for recording Topic 4–8 practical evidence.

## Evidence types
- Knowledge
- Interactive
- Practical
- Reassessment

## Purpose
Practical performance can now be represented in the same evidence contract while retaining its evidence type and source.

## Safeguard
Practical and knowledge scores are not automatically interchangeable. Production weighting must be defined by teacher/assessment policy.

## Next integration
Add explicit adapters for each Topic 4–8 workspace and practical rubric so every practical criterion maps to an approved skill and lesson identifier.
