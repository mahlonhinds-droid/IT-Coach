# Practical Criterion → Skill Mapping 1.0

The IT Coach prototype now provides adapters that translate practical rubric criteria into universal skill identifiers.

## Purpose
A practical result should identify the skill demonstrated, not only the overall task score.

Examples:
- Topic 5 formula/absolute-reference criteria → formula-functions
- Topic 5 sorting/find criteria → data-management
- Topic 5 chart/worksheet criteria → charts
- Topic 6 query criteria → queries
- Topic 6 form/subform criteria → forms-subform
- Topic 6 report criteria → reports
- Topic 7 algorithm/flowchart criteria → algorithms
- Topic 7 trace criteria → trace-tables
- Topic 8 selection/loop criteria → selection-loops
- Topic 8 debugging/documentation criteria → testing-debugging

## Important
These aliases are prototype implementation mappings. Final teacher-authored rubrics should explicitly identify the approved skill ID rather than relying on keyword matching.

## Evidence-aware decisions
The mastery decision layer can now distinguish whether a recommendation is supported by multiple evidence types, such as knowledge plus practical evidence.

This is an evidence architecture, not an official CXC grading calculation.
