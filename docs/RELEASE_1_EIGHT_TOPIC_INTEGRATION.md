# Release 1 — Eight-Topic Content Integration Plan

## Source basis
The supplied IT Coach CSEC Workbook Complete Draft 2026 is the source of truth for the curriculum structure. The app must preserve the workbook's topic and lesson organization. Where the available draft versions differ in lesson naming or scope, the content team must select the intended final edition before production merge.

## Eight-topic engine
1. Fundamentals of IT
2. Networks and Communication
3. Social and Economic Impact of IT
4. Word Processing, Presentations and Web Pages
5. Spreadsheets
6. Databases
7. Problem Solving and Program Design
8. Programming in Pascal

## Integration sequence
- Stage A: curriculum catalog and stable IDs
- Stage B: lesson objectives and approved content blocks
- Stage C: knowledge checks
- Stage D: practice question bank
- Stage E: topic assessments
- Stage F: mastery and remediation rules
- Stage G: mock examination
- Stage H: teacher assignment/reporting layer

## Important content rule
The student workbook does not contain the separate teacher answer key. Do not invent official answers, marking guidance, or teacher-only material. When teacher books are supplied, answer keys and marking guidance will be mapped into teacher-facing records.

## Current status
Topic 1 is the Release 1 reference implementation. The eight-topic catalog is now committed to the development branch. The next content build should expand Topics 2–8 using the same engine rather than creating separate applications.
