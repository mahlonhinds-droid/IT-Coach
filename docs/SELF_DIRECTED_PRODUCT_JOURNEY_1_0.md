# Self-Directed Product Journey 1.0

## Entry
Learner creates/starts a learner profile and chooses self-directed mode.

## Core journey
1. Diagnostic
2. Personalized topic path
3. Learn
4. Interactive activity
5. Practice
6. Assessment
7. Evidence-based diagnosis
8. Targeted intervention
9. Reassessment
10. Mastery/growth
11. Continue to another topic

## Teacher transition
A learner may later move into teacher-assigned mode without losing accumulated browser evidence in the prototype data model.

## Design principle
The platform should never make teacher assignment a prerequisite for completing the learning journey.

## Production considerations
For real multi-device use, authentication, cloud synchronization, privacy controls, parental/teacher permissions where applicable, and secure data storage must be added.
