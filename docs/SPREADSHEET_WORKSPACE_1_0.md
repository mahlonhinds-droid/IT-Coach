# Spreadsheet Workspace 1.0

## Browser-only prototype
The first dedicated practical workspace provides:
- 6 × 6 editable cell grid
- browser localStorage persistence
- numeric values
- basic cell arithmetic
- SUM(range)
- AVERAGE(range)
- formula feedback
- draft save

## Curriculum alignment
The workspace is intended to support Topic 5 practice around spreadsheet terminology, formulae/functions, and basic data handling.

## Scope limitation
Sorting, charts, multiple worksheets, absolute references, and richer spreadsheet functions are not yet implemented in this first workspace version.

## Production direction
Add formula dependency handling, absolute references, sorting, charts, multiple worksheets, task templates, teacher-authored answer checks, and artifact export before production use.
