# Student Planner 1.0

The planner unifies teacher-assigned work and independent learning.

## Planner items
- Teacher assignments
- Due dates when supplied
- Priority learning
- Teacher support/intervention items
- Flexible self-directed activities

The planner is intentionally lightweight. It should answer “what do I need to do?” without becoming a full calendar/administration system.

## Independence
A learner without a teacher still receives a useful planner through adaptive recommendations and personal goals.

## Classroom mode
When assignments exist, they appear alongside the learner's adaptive plan rather than replacing it.
