# IT Coach Class Intervention Loop 1.0

## Workflow
1. Teacher opens the class dashboard.
2. System groups students by topic status.
3. Teacher selects a topic intervention.
4. Eligible students are identified from recorded topic evidence.
5. Teacher assigns targeted remediation or practice.
6. Students follow their individual learning paths.
7. Reassessment produces new evidence.
8. Teacher reviews class growth.

## Prototype bands
- Remediation: below 70%
- Practice: 70–79%
- Consolidation: 80%+
- Unassessed: no score

These are prototype diagnostic bands, not official CXC grading rules.

## Production requirement
Real class deployments require authenticated student records and secure multi-device synchronization.
