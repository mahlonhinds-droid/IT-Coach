# Web Page Design Workspace 1.0

## Browser-only prototype
Students can:
- set a page title
- create a heading
- enter body content
- select text/background colours
- choose left, centre or right alignment
- see an in-page preview
- open a rendered preview
- save a browser-local draft
- submit for teacher review

## Topic 4.4 alignment
This provides an initial practical environment for web page design and development.

## Prototype validation
Teacher-authored checks can verify title, heading, body content and basic styling.

## Production direction
Add semantic HTML elements, hyperlinks, images, lists, tables, navigation, CSS layout and source-mapped web design tasks. Formal assessment should use teacher-approved criteria aligned to final source materials.
