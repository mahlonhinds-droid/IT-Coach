# Topic 4 Practical Remediation and Reassessment 1.0

Practical evidence scoring now feeds a targeted revision prototype.

## Flow
1. Score the practical artifact/evidence.
2. Identify unmet rubric criteria.
3. Map each unmet criterion to the relevant Topic 4 lesson.
4. Present targeted revision guidance.
5. Student revises the artifact.
6. Rescore the practical work.
7. Show score change from the previous result.

## Prototype mastery rule
- 80–100: prototype mastery threshold met
- below 80: continue targeted revision

These are configurable learning rules and are not official CXC grading thresholds.

## Example
A Mail Merge result may identify:
- merge fields not demonstrated
- preview not demonstrated

The student is directed back to the relevant 4.2 learning area before reassessment.

Teacher review remains important for formal practical assessment.
