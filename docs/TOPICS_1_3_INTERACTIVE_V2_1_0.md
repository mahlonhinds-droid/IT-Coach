# Topics 1–3 Interactive Activities v2

The Topics 1–3 interactive layer has been upgraded with richer activity patterns.

## Included
- scenario decision activities
- sequencing activities
- matching/evidence activities
- immediate correctness feedback
- explanatory feedback framework
- student evidence capture
- browser-only persistence

## Topic coverage
Topic 1: hardware, information processing, troubleshooting
Topic 2: networks, transmission media, web services
Topic 3: security, countermeasures, digital ethics

## Product direction
The current controls are a browser-only foundation. The next UI maturity step can introduce true drag-and-drop, animated diagrams, richer question variants, accessibility/keyboard support and more granular mastery evidence.

All activities remain author-created prototype learning content, not official CXC examination items or marking schemes.
