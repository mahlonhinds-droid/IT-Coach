# Topic 6 Live Forms and Reports 1.0

The database learning prototype now renders saved form definitions as usable browser-local data-entry forms and saved report definitions as grouped/sorted report views.

## Student actions
- Open a saved form.
- Enter record values.
- Add the record to the selected table.
- Open a saved report.
- View records grouped by the chosen field and sorted by the chosen field.

## Scope
This is an educational prototype, not a commercial DBMS. Data remains in localStorage and there is no server-side multi-user database.
