# Final Crunch Exam Prep 1.0

IT Coach includes a configurable **14–30 day final exam preparation mode**.

## Four phases

1. **Diagnose & Prioritize (15%)**
   - diagnostic review
   - identify weakest skills
   - identify unassessed topics

2. **Targeted Revision (35%)**
   - weakest topics first
   - misconception correction
   - guided practice
   - retrieval practice

3. **Exam Practice (30%)**
   - timed questions
   - mixed-topic practice
   - structured responses
   - practical work for Topics 4–8

4. **Final Simulation (20%)**
   - timed mock examination
   - error analysis
   - final targeted revision
   - confidence check

## Available durations

- **14 days:** intensive emergency preparation
- **21 days:** balanced final preparation
- **30 days:** recommended full crunch period

The system can personalize topic emphasis from the student's evidence rather than giving every learner the same revision schedule.

## Daily rhythm

A typical day can contain:
- 30–45 minutes targeted revision
- 30–45 minutes exam questions
- 20–30 minutes error correction/retrieval
- 20–40 minutes practical/programming work on selected days

The plan is configurable and is **not an official CXC timetable or grading policy**.
