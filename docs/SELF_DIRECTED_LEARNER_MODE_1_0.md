# Self-Directed Learner Mode 1.0

IT Coach supports two modes:

- **Self-directed:** student can use the platform without an assigned teacher.
- **Teacher-assigned:** student can participate in a teacher-managed class.

## Self-directed experience
The student receives:
- diagnostic assessment when evidence is missing;
- personalized learning routes;
- targeted revision/practice/application;
- progress and mastery history;
- intervention recommendations;
- reassessment and growth tracking.

## Three-failure rule in self-directed mode
Three below-threshold attempts still identify a persistent skill difficulty, but there is no teacher to alert. The system therefore provides a stronger self-support route and keeps the skill visible in the learner's progress profile.

If a teacher is later assigned, the accumulated evidence and intervention history can become the starting point for teacher review.

## Product principle
Teacher involvement is an enhancement, not a prerequisite for learning. The same evidence model should support independent learners and classroom learners.

This is a browser-only prototype architecture. A production system would require account identity, secure cloud persistence, privacy controls, and role-based access.
