# Unified 8-Topic Student Journey 1.0

The eight topic adapters are now connected to a common student journey model.

## Common stages
Learn → Practice → Assess → Diagnose → Targeted Revision → Reassess → Mastery → Portfolio

## Learning mode
Topics 1–3 use knowledge assessment and scenario practice as their default prototype mode.

Topics 4–8 use mixed knowledge/practical mode and can route into their topic-specific workspaces and activities.

## Integration principle
Existing topic-specific engines remain authoritative for their own activities. The unified adapter provides orchestration rather than replacing those engines.

## Current scope
This is a browser-only foundation. It does not yet claim that every topic has the same depth of practical implementation. Topic 4 and Topic 6 currently have substantially developed practical pathways; other topics can be progressively connected.

## Next production concern
Student identity, class membership, teacher permissions, assessment records and synchronized progress will eventually need a backend. The current prototype intentionally remains browser-only.
