# Topic 6 Main Form + Sub-form 1.0

The prototype now demonstrates the Topic 6 relationship between a main form and related records in a sub-form.

## Demo structure
Main form: STUDENT

Sub-form: LOAN

The sub-form displays related loan records for the selected student and allows a new related loan record to be added.

## Learning purpose
This demonstrates the concept of using a main form to identify one record while a sub-form displays related records.

## Source alignment
The Complete Draft explicitly includes a form with a main form and sub-form in its SBA-oriented database guidance.

## Prototype limitation
The demo currently uses browser-local data and simplified controls. It is not a full database-management system and does not yet enforce referential integrity or provide a production form designer.
