# IT Coach Adaptive Assessment UI 1.0

## Student flow
The prototype now exposes a student-facing targeted assessment interface backed by the curriculum-linked question bank.

Flow:
1. Start assessment for a topic.
2. Receive randomized tagged questions.
3. Submit responses.
4. Calculate overall score.
5. Calculate skill-level scores.
6. Identify the lowest recorded skill.
7. Recommend Remediate, Practice/Review or Consolidate.
8. Offer reassessment.

## Evidence rule
Skill results come from questions explicitly tagged to the skill. The system does not infer a skill score from an overall topic score.

## Prototype status
Question wording and answer keys are demonstration material and require approval against final workbook/teacher materials before production.
