# Word Processing Workspace 1.1

## Added
- table insertion
- editable table cells
- mail-merge template insertion using fields such as {{FirstName}} and {{Organisation}}
- sample mail-merge preview
- basic document layout controls

## Curriculum alignment
These features are intended to support Topic 4.2: advanced word processing, including tables, mail merge and forms.

## Important scope note
The mail-merge feature is a learning simulation, not a full office-suite mail-merge engine. Teacher-authored tasks and rubrics should be reviewed against the final approved workbook/teacher materials before formal assessment use.
