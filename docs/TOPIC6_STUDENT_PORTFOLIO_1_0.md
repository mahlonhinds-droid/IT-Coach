# Topic 6 Student Achievement Portfolio 1.0

The Topic 6 prototype now keeps browser-local practical mastery history by student.

## Portfolio shows
- number of attempts
- first overall score
- latest overall score
- overall growth
- first/latest score by skill
- skill-level growth
- achievement history with status and date

## Learning purpose
Students can see improvement over time rather than being defined only by their most recent result.

## Intended cycle
Practical attempt → feedback → targeted revision → reassessment → portfolio growth.

## Scope
Browser-only prototype using localStorage. Production implementation should use authenticated student records and teacher-approved evidence.
