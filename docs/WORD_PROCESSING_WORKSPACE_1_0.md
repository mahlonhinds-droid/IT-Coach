# Word Processing Workspace 1.0

## Browser-only prototype
Students can:
- create/edit document content
- apply bold, italic and underline
- apply a heading
- create an unordered list
- save a draft in localStorage
- submit the document for browser-local teacher review

## Prototype validation
Teacher-authored prototype checks can look for required document structures such as headings, substantive text, formatting and lists.

## Topic 4 alignment
This supports Topic 4.1 word processing practice around creating, formatting and editing.

## Production direction
Add richer formatting, tables, page layout, mail merge/forms, document export, teacher-authored rubrics and artifact review. These should be mapped to the final approved workbook and teacher materials before formal assessment use.
