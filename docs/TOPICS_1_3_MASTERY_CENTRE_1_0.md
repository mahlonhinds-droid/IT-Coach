# Topics 1–3 Mastery Centre 1.0

Topics 1–3 now have the same major mastery-cycle concepts used by the more developed practical topics.

## Student
Skills Lab → Evidence → Score → Mastery Status → Weak-Lab Priority → Targeted Reassessment → Portfolio Growth

## Teacher
Topic → Lab/skill priority → Number of students needing support → Intervention priority

Prototype intervention priority:
- High: 5+ students
- Medium: 3–4
- Low: 1–2

## Portfolio
Tracks:
- attempts
- first score
- latest score
- growth

## Important
This is browser-only prototype functionality. Scores and intervention data are local to the browser and are not yet synchronized across teacher/student devices.
