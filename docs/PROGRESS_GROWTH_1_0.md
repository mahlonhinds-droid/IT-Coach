# IT Coach Progress & Growth 1.0

## Purpose
Show change over time rather than only the latest score.

## Recorded evidence
The browser-only prototype can store assessment events with:
- topic
- score
- assessment event
- timestamp

## Growth
For each topic:
- attempts
- first recorded score
- latest recorded score
- point growth

## Interpretation
Growth is a progress indicator, not an official grade.

## Production expansion
Add skill-level growth, lesson completion trends, practice accuracy, reassessment gains, time-to-mastery and teacher class trends after authenticated cloud persistence is introduced.
