# Student Mastery Profile 1.0

The student experience now has a unified mastery profile foundation.

## Profile includes
- overall assessed average
- number of topics assessed
- topics at Mastered status
- eight-topic status overview
- skill-level evidence where available
- five lowest demonstrated skills
- personalized next-step information
- browser-based growth timeline

## Learning model
The profile is intended to move beyond a single grade by combining:
- knowledge assessment evidence
- interactive activity evidence
- practical/prototype evidence where available
- progress history

## Prototype limitation
The current profile only displays evidence available in the existing browser data contracts. Topic-specific practical evidence is not yet normalized into one universal skill record for all eight topics.

The profile is not an official CXC gradebook or reporting system.
