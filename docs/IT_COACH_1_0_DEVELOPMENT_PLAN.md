# IT Coach 1.0 Development Plan

## Release 0 — Protected baseline
The existing `main` branch remains unchanged and is the protected working prototype.

## Release 1 — Core learning engine
1. Course selector for K–12 and CSEC.
2. Topic → lesson → activity navigation.
3. Knowledge checks.
4. Practice engine.
5. Assessment engine.
6. Mastery calculation.
7. Revision recommendation.
8. Student progress dashboard.

## Release 2 — CSEC content expansion
Implement the eight CSEC topics using the finalized student workbook as the content source.

## Release 3 — Teacher layer
Use the teacher books when supplied to add lesson guidance, answer keys, marking guidance, assignments, common errors and remediation resources.

## Release 4 — Practical learning
Add spreadsheet, database, algorithm/flowchart and Pascal practical activities where supported by the curriculum materials.

## Release 5 — AI Coach
The AI Coach should be grounded in the approved course content and should guide students rather than simply provide answers.

## Release 6 — Pilot platform
Hosted web app, responsive mobile/desktop experience, controlled user testing, reporting and reliability testing.

## Release discipline
Every release is developed on a feature branch, tested, and reviewed before merging to `main`. No direct replacement of the protected baseline without approval.
