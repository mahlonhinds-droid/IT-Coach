# Teacher Intervention Centre 1.0

## Purpose
Turn assessment evidence into teacher actions.

## Prototype indicators
- Students/topics requiring remediation
- Students/topics requiring practice
- Consolidated evidence
- Not-assessed areas
- Priority weakness
- Targeted assignment action

## Current browser-only scope
The prototype operates on assessment and assignment records available in the current browser.

## Production class model
A production release must add authenticated teacher accounts, class membership, individual student records, secure cloud persistence, role permissions and audit controls.

## Intervention loop
Evidence → Priority → Assignment → Student remediation → Reassessment → Updated evidence.
