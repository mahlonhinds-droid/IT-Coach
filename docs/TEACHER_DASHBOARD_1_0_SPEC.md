# IT Coach Teacher Dashboard 1.0

## Purpose

Give teachers useful learning evidence without exposing unfinished teacher-book content or inventing marking rules.

## Dashboard sections

### Class overview
- number of students
- average mastery
- students needing remediation
- students ready for consolidation
- recent assessment activity

### Topic performance
For each topic:
- average mastery
- lesson completion
- knowledge-check performance
- practice performance
- assessment performance
- most common weak objectives

### Student detail
- profile
- completed lessons
- assessment attempts
- mastery history
- recommended intervention
- reassessment status

### Assignment workflow
Teacher can:
- select topic/lesson
- select practice or assessment
- assign to a class or student
- set due date when the future data model supports it

### Teacher review controls

Content and assessment items should carry source status:
- source-derived
- IT Coach interaction
- pending teacher review
- approved for student use

Teacher answer keys and marking guidance remain separate from student-facing content until supplied and reviewed.

## Browser-only phase

For the current prototype, teacher data may be stored locally in the browser. This is a demonstration architecture, not a multi-device classroom system.

Cloud synchronization, accounts, class rosters and permissions belong to the later hosted-data phase.
