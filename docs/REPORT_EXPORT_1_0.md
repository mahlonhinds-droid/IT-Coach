# IT Coach Report Export 1.0

## Prototype
Student and class reports can be opened in a print-friendly page and use the browser print dialog to print or save as PDF.

## Student report
Includes latest score, growth, attempts, strengths, priority areas and recommended next step.

## Class report
Includes class size, topic averages and intervention-status counts for Topics 1–8.

## Limitation
This is browser-side printing, not server-generated PDF. It requires the browser's print/save-as-PDF capability.

## Production
Production can add branded PDF generation, date ranges, teacher comments, parent/student sharing controls and audit history.
