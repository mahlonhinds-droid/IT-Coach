# IT Coach Personalized Learning Path 1.0

## Purpose
Convert evidence into a concrete sequence of student actions.

## Path
1. Review priority skill.
2. Complete guided learning activity.
3. Complete targeted practice.
4. Take reassessment.
5. Confirm mastery.
6. Move to the next priority skill.

## Selection
The prototype prioritizes the lowest recorded skill score below 80%. If no scored weak skill exists, an unassessed skill may be selected. If all recorded skills are at least 80%, the path becomes consolidation.

## Integrity
A path may only reference verified lesson/practice mappings. Missing mappings must be surfaced for teacher review.

## Pilot persistence
Saved paths are stored in browser localStorage.
