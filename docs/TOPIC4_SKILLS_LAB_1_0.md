# Topic 4 Skills Lab 1.0

The Skills Lab adds practical scenario-based activities across the four Topic 4 areas.

## Challenges
1. School Secretary Challenge — document creation/formatting
2. Newsletter Challenge — columns/page features/review
3. Mail Merge Challenge — primary document/data-file workflow
4. Electronic Form Challenge — content controls
5. School Club Website Challenge — planning/content/hyperlinks
6. Website Testing Challenge — links/accuracy/usability
7. Prize-Giving Presentation — slide design and delivery
8. Integrated Topic 4 Practical — combined document, mail merge, web and presentation work

Students can start a challenge, record evidence, save it in browser storage and submit it for teacher review.

## Assessment status
These are author-created practice activities mapped to the Complete Draft content. They are not official CXC assessment tasks or official CXC marking schemes.

## Next development
Connect each lab to the corresponding workspace, add structured rubrics, automatic evidence checks where appropriate, teacher assignment controls and progress/mastery tracking.
