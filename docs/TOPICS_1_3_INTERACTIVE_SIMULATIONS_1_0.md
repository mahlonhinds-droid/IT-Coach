# Topics 1–3 Interactive Simulations 1.0

The browser-only prototype now includes interactive activity patterns for Topics 1–3.

## Topic 1
- Hardware/task matching
- Information-processing sequencing
- Troubleshooting sequencing
- Computer-system visual explorer

## Topic 2
- School network scenario
- Transmission-media matching
- Internet-service decision
- Network visual explorer

## Topic 3
- Security case decision
- Countermeasure matching
- Digital ethics decision
- Digital safety visual explorer

These activities are author-created prototype learning interactions. They are not official CXC assessment items or marking schemes.

The next maturity step is to replace the simple prototype controls with richer drag-and-drop interactions, animated diagrams, more question variants, immediate explanatory feedback, accessibility controls and stronger evidence capture.
