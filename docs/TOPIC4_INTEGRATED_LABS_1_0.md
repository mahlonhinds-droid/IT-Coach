# Topic 4 Integrated Skills Labs 1.0

The Topic 4 Skills Lab now launches the appropriate practical workspace.

## Workspace routing
- School Secretary Challenge → Word Processing Workspace
- Newsletter Challenge → Word Processing Workspace
- Mail Merge Challenge → Word Processing Workspace
- Electronic Form Challenge → Word Processing Workspace
- School Club Website Challenge → Web Page Workspace
- Website Testing Challenge → Web Page Workspace
- Prize-Giving Presentation → Presentation Workspace
- Integrated Topic 4 Practical → integrated activity pathway

## Browser-only evidence
Lab submissions are retained in localStorage. Submission events can also be recorded in the existing progress-history engine.

## Development status
This is a prototype integration. Workspace artifacts, structured rubric scoring and teacher approval are still required before formal assessment use.
