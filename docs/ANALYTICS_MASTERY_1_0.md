# IT Coach Analytics & Mastery 1.0

## Evidence
The prototype summarizes topic assessment scores stored in browser storage.

## Mastery bands
- Below 70%: Remediate
- 70–79%: Practice / Review
- 80%+: Consolidate

These thresholds are prototype diagnostic rules and are not official CXC grades.

## Dashboard outputs
- Number of topics assessed
- Average assessed mastery
- Topic-level score
- Topic status
- Weakest assessed topic
- Recommended next action

## Adaptive loop
Assessment evidence → identify weak topic → targeted remediation/practice → reassessment → updated mastery.

## Future analytics
Production should add objective/skill-level evidence, lesson completion, knowledge checks, practical activity results, assessment history, class trends, growth over time and teacher-configured interventions.
