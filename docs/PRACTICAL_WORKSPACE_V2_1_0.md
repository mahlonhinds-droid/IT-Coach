# Practical Workspace V2 — 1.0

The prototype now supports browser-only practical workspaces for mapped application activities.

## Student capabilities
- Open a mapped practical activity.
- Enter evidence/work notes against each required evidence item.
- Save a draft to localStorage.
- Reopen the draft in the same browser.
- Submit the draft for teacher review.
- Keep the workflow server-free.

## Scope
This is a lightweight evidence workspace, not a full office-suite emulator. It does not yet create native Word, spreadsheet, database or Pascal files.

## Production direction
The next implementation should provide dedicated workspace modes for:
- word processing
- presentations
- web page design
- spreadsheets
- databases
- algorithm/flowchart design
- Pascal programming

Teacher review and artifact handling should be added before practical work is treated as formal assessment.
