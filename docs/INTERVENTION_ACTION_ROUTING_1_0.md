# Intervention Action Routing 1.0

The personalized intervention layer is now connected to existing learning destinations.

## Flow
1. Universal evidence identifies the priority skill.
2. Intervention engine chooses revision, practice, or application.
3. Action router maps the skill to an existing lesson/workspace.
4. Student starts the recommended action.
5. Intervention is recorded in browser storage.
6. Later evidence is compared with prior evidence.
7. The outcome engine recommends collecting evidence, reassessing, or advancing.

## Scope
The current mapping is a prototype routing layer. Existing lesson/workspace IDs must be validated as the runtime UI evolves.

## Safety
No CXC grading rule is implied. Thresholds remain configurable prototype policy.
