# Universal Evidence & Mastery 1.0

IT Coach now has a common browser-only evidence contract intended to normalize learning evidence across all eight topics.

## Evidence types
- Knowledge Assessment
- Interactive Activity
- Practical Evidence
- Reassessment

Each evidence record can contain:
- student
- topic
- lesson
- skill
- evidence type
- score
- source
- evidence reference
- timestamp

## Purpose
The common model allows the future student mastery profile to combine different forms of demonstrated learning without pretending that every assessment has the same meaning.

## Current implementation
Interactive Topics 1–3 and adaptive assessment evidence have bridge functions into the universal model.

Practical evidence from Topics 4–8 still needs explicit adapters into this contract.

## Safeguard
The score/status bands are prototype product rules. They are not official CXC grading rules, and practical/knowledge evidence should be weighted by teacher-approved assessment policy before production use.
