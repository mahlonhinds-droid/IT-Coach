# IT Coach 1.0 Integration & QA Plan

## Goal
Stabilize the foundation before adding major features.

## Test layers
1. Load/runtime integrity
2. Navigation and module availability
3. Student journey
4. Self-directed journey
5. Teacher-assigned journey
6. Evidence/mastery flow
7. Three-failure intervention
8. Exam preparation flow
9. Browser-only persistence
10. Accessibility and mobile layout

## Critical student path
Home -> Topic -> Lesson -> Activity -> Practice -> Assessment -> Diagnosis -> Remediation -> Reassessment -> Mastery -> Next Action.

## Exam path
Readiness -> Crunch plan -> Mock -> Error analysis -> Remediation -> Simulation trend -> 7-day countdown -> Exam day -> Reflection.

## Release rule
No production claim until the current branch has been executed in a real browser and critical-path defects are resolved.
