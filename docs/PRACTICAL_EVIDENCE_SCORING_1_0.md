# IT Coach Practical Evidence Scoring 1.0

## Purpose
Provide a prototype evidence model for application activities in Topics 4–8.

## Model
Each activity defines observable evidence. Evidence items have configurable weights. A prototype score is calculated from the evidence selected as demonstrated.

Bands:
- below 70: foundation/remediation
- 70–84: developing
- 85–100: application/consolidation

## Browser-only prototype
Evidence and results are stored in localStorage. No server persistence is used.

## Production safeguards
This is not an official CXC marking scheme. Teacher-authored marking criteria must replace the prototype weights before formal assessment. Practical workspaces should eventually capture actual artifacts (documents, spreadsheets, databases, algorithms, Pascal programs) and support teacher review, rather than relying only on a checklist.
