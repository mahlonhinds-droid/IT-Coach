# Practical Activity Source Notes

The first practical activity engine uses small browser simulations to demonstrate the runtime contract.

## Source-derived task basis

The supplied Complete Draft contains practical/exam-style coverage for Topics 4-8 and identifies practical assessment content in those areas. Its question bank is original and author-created, not an official CXC mark scheme.

The current activity engine therefore uses:
- Spreadsheet formula practice
- Database query-condition practice
- Algorithm trace practice
- Pascal assignment practice

These are **prototype interactive activities**, not claimed to be exact copies of workbook questions or official CXC tasks.
