# Personalized Intervention Engine 1.0

The universal mastery layer now produces an intervention mode from the weakest demonstrated skill.

## Prototype routing
- Below 70 → Revision
  - Review lesson
  - Guided example
  - Foundational practice
- 70–84 → Practice
  - Targeted practice
  - Scenario activity
  - Feedback
- 85+ → Application
  - Advanced application
  - Integrated task
  - Reflection

If no evidence exists, the engine recommends diagnostic assessment.

## Evidence context
The engine also reports whether the recommendation has multiple evidence types, such as knowledge plus practical evidence.

## Progress
Intervention actions can be recorded in browser storage and later compared with subsequent universal evidence to estimate skill growth.

Thresholds and action mappings are prototype rules and must remain configurable/teacher-approved.
