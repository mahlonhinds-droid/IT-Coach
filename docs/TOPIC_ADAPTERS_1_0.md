# IT Coach Topic Adapter Registry 1.0

A reusable registry now maps all eight CSEC topics to their learning skill domains.

## Topics
1. Fundamentals of IT
2. Networks and Communication
3. Social and Economic Impact of IT
4. Word Processing, Presentations and Web Pages
5. Spreadsheets
6. Databases
7. Problem Solving and Program Design
8. Programming in Pascal

The adapter layer lets the platform keep one Mastery Centre architecture while each topic supplies its own skill map.

## Source alignment
The topic names and skill areas follow the current Complete Draft lesson structure. Detailed assessment criteria remain configurable and should be teacher-reviewed before formal use.

## Intended next integration
Connect each topic adapter to its existing question bank, practical workspace/application activities, remediation launcher, reassessment engine, progress history and teacher reporting.
