# Skill / Objective Analytics 1.0

## Purpose
Move from topic-level mastery to objective-level evidence where the assessment engine records skillScores.

## Evidence rule
The dashboard must display only recorded assessment evidence. It must not manufacture or infer a skill score from an overall topic score.

## Status bands
- Below 70%: Remediate
- 70–79%: Practice / Review
- 80%+: Consolidate

These are prototype diagnostic bands, not official CXC grading.

## Current source mapping
The skill/objective labels use the current Complete Draft lesson map for Topics 1–8. Detailed objective-level production analytics require the approved question bank to carry objective/skill tags.

## Future behavior
Weak objective → identify matching lesson → assign targeted practice → reassess the objective → update mastery.
