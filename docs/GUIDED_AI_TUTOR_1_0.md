# IT Coach Guided AI Tutor 1.0

## Teaching dialogue
The prototype follows:
1. Explain
2. Example
3. Guided Question
4. Feedback
5. Practice

## Student participation
The student supplies a free-text response at each turn.

## Prototype limitation
The deterministic prototype records the response for the browser session but does not automatically award marks for free-text answers.

## Production AI
A production implementation should retrieve approved lesson content, provide age/level-appropriate explanations, evaluate responses against approved criteria where appropriate, cite the lesson/objective used, and escalate ambiguous or high-stakes marking to teacher review.
