# IT Coach Classroom / Cohort 1.0

## Purpose
Extend the individual adaptive-learning prototype to a teacher classroom view.

## Prototype capabilities
- Create a demo class
- Add students
- View class size
- View topic-level intervention counts
- Distinguish remediation, practice, consolidation and unassessed states
- Store class records in browser localStorage

## Production transition
The browser prototype does not provide real multi-device class synchronization. Production requires authenticated accounts, secure cloud persistence, teacher/student role permissions, class membership and privacy/audit controls.

## Future teacher action
Select a topic and affected students → assign targeted learning path → monitor completion → review reassessment growth.
