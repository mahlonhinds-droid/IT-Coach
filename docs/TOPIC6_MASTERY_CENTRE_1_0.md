# Topic 6 Mastery Centre 1.0

The Topic 6 prototype now has a unified student-facing mastery view.

## It combines
- latest practical mastery score
- mastery status
- overall growth
- four database skill scores
- immediate revision recommendations
- access to achievement portfolio
- access to targeted remediation

## Student decision logic
No assessment → start the Database Practical.

Any skill below 80% → targeted revision is recommended.

All skills at or above 80% → consolidation/extension is recommended.

The thresholds are configurable prototype rules and are not official CXC grading boundaries.

## Architecture
Practical → Evidence → Skill Scores → Mastery Centre → Revision/Reassessment → Portfolio Growth.
