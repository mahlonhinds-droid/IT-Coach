# Topic 6 Database Practical Mastery — Teacher View 1.0

## Student-level view
Teachers can view four prototype practical skill dimensions:
- Database Design
- Queries
- Forms / Sub-form
- Reports

An overall score is calculated as the simple average of the four skill scores.

## Status
- 80–100: Mastered
- 70–79: Developing
- below 70: Intervention

## Class intervention priorities
The view counts students below 80% in each skill and labels the priority:
- High: 5 or more
- Medium: 3–4
- Low: 1–2

These are prototype rules, not official CXC grading rules.

## Browser-only operation
Mastery records are stored in localStorage for demonstration. A production release should connect this view to authenticated student/class records and teacher-approved evidence.
