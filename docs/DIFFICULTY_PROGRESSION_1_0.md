# IT Coach Difficulty Progression 1.0

## Prototype bands
- Foundation: below 70%
- Developing: 70–84%
- Application: 85–100%

## Learning behavior
- Foundation performance keeps the student in remediation/foundation practice.
- Developing performance advances the student into developing/application practice.
- Strong performance moves the student toward application/consolidation.

## Important
These thresholds are configurable prototype rules, not official CXC grading standards. Production thresholds should be validated using approved assessment design and teacher review.

The application band is a planned content category; the current prototype question bank does not yet contain a complete application-level item set for every skill.
