# IT Coach Targeted Revision Loop 1.0

Assessment results now provide a direct targeted-revision action.

Flow:
1. Student completes a curriculum-linked assessment.
2. Skill scores are calculated from tagged questions.
3. Lowest recorded skill is identified.
4. Student selects Targeted Revision.
5. Runtime resolves the tagged question's lesson.
6. The matching lesson content/activity is displayed where source-mapped content exists.
7. Student can practice that lesson or reassess.

If no verified lesson mapping exists, the system displays a teacher-review message rather than inventing a curriculum mapping.

Prototype mastery thresholds remain diagnostic only.
