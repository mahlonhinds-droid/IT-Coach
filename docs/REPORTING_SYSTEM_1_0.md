# IT Coach Reporting System 1.0

## Student report
The prototype report can show:
- latest recorded topic score
- point growth
- assessment attempts
- strongest recorded skills
- weakest recorded skills
- current personalized learning path

## Class report
The prototype can show:
- class size
- topic averages where scores exist
- remediation count
- practice count
- consolidation count
- unassessed count

## Interpretation
Reports are learning-progress indicators. Prototype mastery bands are diagnostic rules, not official CXC grades.

## Production requirements
Production reports require authenticated student records, secure persistence, teacher permissions, export/print controls and approved assessment data.
