# Topic 4 Teacher View 1.0

## Class practical skills overview
The prototype summarizes the latest recorded practical score for each Topic 4 challenge and classifies the overall practical status.

Status bands:
- 80–100: Mastered
- 70–79: Developing
- below 70: Intervention
- no score: Unassessed

## Intervention priorities
The teacher view also counts recurring unmet evidence criteria across recorded attempts, helping identify common class-level skill gaps.

## Browser-only limitation
The current prototype reads localStorage, so it is suitable for a single-browser demonstration. It is not yet a multi-device classroom data system.

## Production direction
Connect teacher and student accounts to a backend, preserve student privacy/permissions, support class rosters and assignment-level filtering, and allow teachers to approve or override practical evidence scores.
