# IT Coach Examination Centre 1.0

## Pathways
- Paper 01 — Multiple Choice
- Paper 02 — Structured Response
- Paper 03 — SBA / Practical

## Configurable weighting
The examination engine intentionally stores weighting as configurable/null. The supplied Complete Draft describes an assessment weighting, but draft versions in the project history differ. The final approved workbook/teacher assessment materials must be treated as the source of truth before locking production weights.

## Marking
Paper 01 can be automatically scored for prototype MCQ items.
Paper 02 and Paper 03 are captured as response/practical pathways, but production marking requires approved rubrics, answer keys and marking guidance.

## Scope
The exam centre is browser-only and intended for pilot testing. It does not claim to reproduce an official CXC examination environment.
