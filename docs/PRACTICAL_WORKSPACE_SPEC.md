# IT Coach Practical Workspace Specification

## Goal

Turn the browser-only prototype into an environment where students practise the practical skills represented by Topics 4-8.

## Workspaces

### Word processing
Student actions:
- enter/edit text
- apply formatting
- manipulate tables
- use document features
- complete a production task

### Presentation
Student actions:
- create a slide sequence
- choose appropriate layout/content
- respond to presentation-design prompts
- receive task-based feedback

### Web page
Student actions:
- construct a simple page representation
- identify page elements
- practise HTML/web concepts from the approved lesson content

### Spreadsheet
Student actions:
- enter values
- build formulas
- use functions
- practise relative/absolute references
- sort/find data
- create charts
- work across worksheets

### Database
Student actions:
- identify fields/records
- design tables
- select keys
- build query conditions
- interpret forms/reports

### Algorithm
Student actions:
- decompose a problem
- construct pseudocode
- construct/interpret flowcharts
- complete trace tables

### Pascal
Student actions:
- write small Pascal statements
- identify declarations, input/output and assignment
- practise selection and loops
- inspect errors
- test/debug programs

## Implementation rule

The first versions are simulations/workspaces inside the browser. They do not claim to replace full commercial office/database/IDE software.

Each workspace should return structured results that the mastery engine can record.

## Teacher review

Practical marking criteria must be sourced from the teacher book or explicitly authored and approved before being treated as production marking guidance.
